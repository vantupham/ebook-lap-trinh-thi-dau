# Tập 0 – Nhập môn tư duy lập trình

> **Dành cho:** học sinh lớp 8–9, hoặc lớp 10 mới bắt đầu học lập trình.
> **Kỳ thi đích:** HSG lớp 9 cấp tỉnh/thành phố (thường thi lập trình trên máy, C++/Pascal/Python, 120 phút).
> **Mốc tự đo khi học xong:** giải được bài Codeforces mức 800–1000 trong 20–30 phút.
> **Thời lượng:** 8–10 tuần, 8–12 giờ mỗi tuần.

Tập 0 dạy **song song Python và C++**. Em có thể chọn một ngôn ngữ để học chính, nhưng nên đọc cả bản còn lại: từ Tập 2, bộ sách chuyển hẳn sang C++.

## Cách học một bài

1. Đọc **Bài toán mở màn**, rồi dừng lại 10 phút tự nghĩ. Đừng mở đáp án vội.
2. Đọc phần kiến thức, **gõ lại** code mẫu (không sao chép), chạy thử với ví dụ.
3. Làm bài tập theo thứ tự nấc: Khởi động → Luyện → Thử thách. Kẹt 30 phút thì mở gợi ý.
4. Cuối bài, tự kiểm tra **checkpoint**. Chưa đạt thì ôn lại mục được chỉ.

## Checkpoint cuối Tập 0

Em sẵn sàng sang Tập 1 nếu:

- [ ] Làm đề thi thử ở bài 0.10 trong 120 phút, đạt ít nhất 12/20 điểm.
- [ ] Giải được ít nhất 25 bài trong danh sách bài tập của cả tập.
- [ ] Tự viết không nhìn sách: đọc/ghi tệp, sàng nguyên tố, thuật toán Euclid.

| | Python | C++ |

| Cách dễ nhất | [Thonny](https://thonny.org) (có sẵn Python) | [Code::Blocks](https://www.codeblocks.org) bản có MinGW |
