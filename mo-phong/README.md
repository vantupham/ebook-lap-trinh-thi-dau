Phím tắt: **→** bước tiếp, **←** lùi, **dấu cách** tự chạy/dừng.

Trên github.com, tệp HTML chỉ hiện mã nguồn. Hãy tải về và mở bằng trình duyệt, hoặc bật GitHub Pages (xem README ở thư mục gốc).

Mã nguồn trong `src/`: `engine.js` là phần logic thuần, `test_engine.js` so nó với lời giải vét cạn, `template.html` là giao diện, `build.py` ghép hai phần thành một tệp, `make_svgs.js` sinh hình tĩnh cho bài học.
